# Project-UA-Shield-RuThreat-Intel

This repository is dedicated to the research, analysis, and tracking of cyber threats originating from pro-government and state-sponsored (APT) hacking groups of the Russian Federation targeting Ukraine's critical infrastructure, public sector, and citizens.

## Project Goals

* **Threat Intelligence:** Documenting and analyzing the tactics, techniques, and procedures (TTPs) of Russian threat actors.
* **Indicators of Compromise:** Maintaining an up-to-date database of malware hashes, malicious IP addresses, C2 domains, and phishing infrastructure.
* **OSINT and Analytics:** Publishing detailed investigation reports based on cyberattack analysis and open-source intelligence.
