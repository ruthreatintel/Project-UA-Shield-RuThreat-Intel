# Security Policy

## Supported Versions

This is a live cyber threat intelligence and OSINT project. We continuously update our indicators of compromise (IoCs), phishing infrastructure tracking, and investigation reports.

| Version | Supported          |
| ------- | ------------------ |
| Latest  | :white_check_mark: |
| Older   | :x:                |

We strongly recommend always pulling the latest changes from the `main` branch to ensure you are utilizing the most accurate and up-to-date defensive data.

## Reporting a Vulnerability or Sharing Sensitive Intel

If you find a security vulnerability in our analytical tools, or if you possess **sensitive threat intelligence** (such as active C2 server domains, active phishing links, or confidential malware samples) that should not be exposed to the public yet, **please do not open a public Issue or Pull Request.**

Instead, please report this information directly and securely via email:

* **Contact Email:** ruthreatintel@gmail.com

We will review your submission promptly and coordinate data processing to support the defensive tracking of cyber threats targeting Ukraine's critical infrastructure.
